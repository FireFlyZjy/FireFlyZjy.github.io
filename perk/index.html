这是什么

拾惠是一款纯本地的福利记录工具：把试用、优惠券、会员权益的截止日期记下来，按「今天截止 / 还有 N 天」自动归类，配合桌面与锁屏卡片、系统到期提醒，让你在过期前用掉它们。无账号、记录只存在你的设备上。

核心功能

⏰ 到期提醒系统级代理提醒，支持当天 / 提前 1 天 / 提前 3 天；当天补记也会尽快提醒。
🗓️ 桌面与锁屏卡片2×2 / 2×4 最近到期列表、1×2 / 1×1 一键添加，点击直达。
🔗 快速记录浏览器分享链接给拾惠，或从剪贴板粘贴，自动带出链接与图标。
📁 目录 / 收藏 / 置顶36 色主题、连续翻页顶栏、长按多选、滑动快速勾选。
💾 全量备份本地 .perkdb 容器导出恢复，支持坚果云等 WebDAV 云备份（邀测版）。
🧹 留存统计一键清理已结束、一键再来一期、今年已领取 / 过期未领一目了然。

版本说明

应用市场正式版因上架合规暂未申请联网权限：网站图标自动获取、内置浏览器与 WebDAV 云备份在正式版中不可用（应用内已注明）。 完整体验请安装邀测版。两版均为纯本地记录，卸载即删除数据。
