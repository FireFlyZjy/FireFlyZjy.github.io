拾惠 (Perk) 隐私声明

更新日期：2026-10-31

生效日期：2026-10-31

软件包名：com.zjy.perk

核心承诺：拾惠 (Perk) 是一款纯本地的 AI 福利管理工具，帮你记录各类平台福利的日期与入口、整理链接、日历与领取记录。所有数据仅保存在你的设备本地：不注册账号、不云同步、不上传服务器、不集成任何统计或广告 SDK。内置浏览器只在你主动打开时加载你自己添加的链接；照片经系统选择器选定后复制进应用沙箱；备份文件由你主动导出到本机并自行保管。

1. 我们收集的信息

1.1 本地存储数据

我们仅在您的设备本地存储以下信息（SQLite 数据库与应用沙箱 Preferences）：

  • 福利条目：名称、所属平台、备注、开始与结束日期、置顶与已领取标记、所属目录与收藏状态
  • 链接：你添加的网址 URL、链接标题、用于展示图标的网站域名标识
  • 记录与图片：福利的领取/使用记录；每条记录最多 9 张图片，经系统照片选择器由你主动选定后复制到应用沙箱（原图仍保留在系统相册，由你管理）
  • 回收站：删除的条目先进入回收站，可恢复或彻底删除
  • 外观与偏好：主题色（36 色）、深色模式、弹层材质偏好、列表排序方式
  • 编辑草稿：未保存的编辑内容暂存，便于中断后继续
  • 备份索引：你导出的备份文件名与时间等元数据

1.2 我们不收集的信息

  • 个人身份信息（姓名、邮箱、电话等）
  • 设备标识符（IMEI、OAID 等）
  • 位置信息
  • 通讯录、短信、通话记录
  • 账号信息、登录凭证（本应用无登录功能）
  • 操作行为统计、使用时长、内容偏好（无埋点、无崩溃上报）
  • 浏览历史、书签等浏览器数据（内置浏览器不向运营者上传任何浏览数据）

1.3 内置浏览器

应用内置浏览器基于系统 Web 组件，仅用于加载你主动添加并点击的福利链接。它不注入脚本、不拦截页面内容、不向本应用运营者发送浏览数据；网络访问只发生在你打开链接时。

2. 数据存储与保护

2.1 存储位置

福利、链接、记录、图片与设置保存在设备本地的应用沙箱中（SQLite 数据库与 Preferences）。图片副本保存在沙箱文件目录，应用文件目录形如：

/data/app/el2/100/base/com.zjy.perk/haps/entry/files/

备份导出（Perk-<日期>.perkdb）由你在系统保存确认后写入你选择的本机位置，备份文件由你自行保管；恢复备份时以你选择的本机文件为准。

2.2 数据保护

  • 应用内数据存储于私有沙箱，其他应用无法访问
  • 卸载应用时系统会一并清除沙箱内所有数据
  • 备份文件属你本人的本地文件，随你的保管方式存放与传播

3. 权限说明

权限 类型 用途
ohos.permission.INTERNET system_grant 内置浏览器加载你添加的福利链接。除此之外不用于任何数据传输。
ohos.permission.DETECT_GESTURE system_grant 根据握持方向调整新增按钮和记录封面位置，只读取握持姿态，不采集触屏内容。
系统照片选择器 每次由系统确认 仅在你为记录主动添加图片时弹出，只读取你本次选定的图片，不申请遍历整个相册的权限。

4. 第三方服务

拾惠不集成任何第三方 SDK：无统计 SDK、无广告 SDK、无推送 SDK、无分享 SDK、无崩溃上报、无支付、无账号登录。链接加载能力由 HarmonyOS 系统 Web 组件提供，界面与数据能力由系统 Kit（ArkUI Kit、ArkWeb 等）提供。

5. 儿童保护

本应用不面向儿童设计，不涉及儿童个人信息。应用不提供任何面向儿童的交互或数据收集，也不做内容分级或儿童内容过滤。

6. 数据删除

  • 回收站：删除的条目进入回收站，可随时恢复；「彻底删除」与「清空」不可恢复
  • 记录图片：随所属条目删除，彻底删除时同步清理沙箱内图片副本
  • 彻底清除：卸载应用，系统清除全部沙箱数据；已导出的备份文件与相册原图仍由你保管

7. 本声明的更新

如本声明有重大变更，将在应用内提示更新。当前版本未集成任何远程通知或推送能力，因此声明变更以应用版本更新形式提供。线上版本见 https://fireflyzjy.github.io/perk/privacy/。
