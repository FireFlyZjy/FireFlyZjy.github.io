光影播放器 (Cine) 隐私声明

更新日期：2026-10-30

生效日期：2026-10-30

软件包名：com.zjy.cine

核心承诺：光影播放器 (Cine) 是一款纯本地视频播放器。默认在本机解码播放，不云同步、不统计播放行为。仅当您主动开启投播并选择接收设备时，通过系统投播服务向该设备传输当前视频及必要的播放信息，不上传至本应用运营者服务器。从专属下载目录导入时只保存文件引用与元数据；从文件管理导入时按您的选择复制到应用沙箱。缩略图、截图及其说明只保存在本机，保存相册由系统向您确认。

1. 我们收集的信息

1.1 本地存储数据

我们仅在您的设备本地存储以下信息：

  • 片库索引：视频文件 URI、片名（初始取自文件名，可由您重命名）、所在文件夹、扩展名、时长（毫秒）、体积（字节）、分辨率（宽×高）、入库时间
  • 播放设置：播放模式、音量、播放速度、当前视频 URI 与下标
  • 续播位：按视频 URI 独立保存的播放进度（毫秒）
  • 本地图像：视频封面缩略图；您主动截取的 JPEG 视频帧，以及对应视频标题、URI、播放位置、创建时间和已保存相册标记。截图默认每张请求保存相册，也可先留在应用内后批量保存。
  • 外观设置：主题色索引、深色模式开关
  • 列表设置：排序方式
  • 界面设置：系统音量弹窗与系统状态栏偏好、握持与播放方向设置
  • 使用 Preferences API 存储于应用沙盒目录

1.2 我们不收集的信息

  • 个人身份信息（姓名、邮箱、电话等）
  • 设备标识符（IMEI、OAID、IDFV 等）
  • 位置信息
  • 通讯录、联系人信息
  • 短信、通话记录
  • 账号信息、登录凭证（本应用无登录功能）
  • 视频、缩略图和截图的运营者服务器副本（用户主动投播至所选接收设备除外）
  • 任意相册图片（截图导出只写入系统确认创建的目标，不遍历您的相册）
  • 播放行为统计、观看时长、内容偏好（无埋点）

1.3 主动投播与播放器状态

投播设备发现、认证和连接由系统服务处理，只有您主动选择设备后才传输视频与播放控制信息。播放器仅为当前状态条读取电量和网络连接类型，内置字幕和音轨在本机解析，不统计您的观看内容。

2. 数据存储与保护

2.1 存储位置

应用内视频副本、封面和截图等文件保存在设备本地的应用沙箱中；片库与设置由本地 Preferences 管理。应用文件目录为：

/data/app/el2/100/base/com.zjy.cine/haps/entry/files/

专属下载目录中的视频按文件引用导入；通过文件管理导入的视频会复制到应用沙箱。视频元数据与封面仅用于本机片库。截图保存在沙箱 screenshots/ 中，默认相册保存成功后会清除该临时截图，取消或失败则保留供后续处理；选择先存应用内时保留原图及记录。相册导出通过一次系统确认批量创建目标后写入图片，每批最多 100 张。

2.2 数据保护

  • 应用内数据存储于私有目录；专属下载视频保留在本地下载目录，已导出图片保留在系统相册
  • 卸载应用时系统会一并清除沙盒内所有数据
  • 片库可在「设置 → 清空片库」中手动一键清空
  • 视频长按进入选择后可执行移入回收站或彻底删除；应用内截图在截图管理中单独清理

3. 权限说明

权限 类型 用途
ohos.permission.GET_NETWORK_INFO system_grant 播放页状态条显示当前网络连接类型（Wi-Fi / 移动网络 / 以太网 / 离线），不传输任何数据。
ohos.permission.VIBRATE system_grant 进度条拖动到片头/片尾边界等操作时给予轻微震动反馈。
ohos.permission.FILE_ACCESS_PERSIST system_grant 记忆您通过系统选择器授权的目录，避免每次导入重复授权；只在您选择的目录内读取视频文件。
ohos.permission.DETECT_GESTURE system_grant 根据握持手状态将视频封面显示在非握持侧，只读取握持姿态，不采集触屏内容。
ohos.permission.KEEP_BACKGROUND_RUNNING system_grant 将播放注册为 AUDIO_PLAYBACK 长时任务，使锁屏、切后台后视频继续播放。
系统相册创建确认 每次由系统确认保存的图片数量 只在您点击保存并同意后写入本次截图，不申请读取整个相册的权限。camera 图标用于视频抽帧，不调用摄像头或系统录屏。

关于后台播放权限：KEEP_BACKGROUND_RUNNING 属系统级授权。开发调试阶段可直接申请；正式签名上架需在 AppGallery Connect 申请 ACL 白名单。若未获授权，光影播放器会静默降级为前台播放，不会弹窗索要额外权限，也不会因此收集任何信息。

关于文件访问：文件管理导入由您在系统选择器中主动选择；从下载目录导入只扫描系统提供的 Cine 专属下载目录及其子目录，用文件引用加入片库，重复文件跳过。

4. 第三方服务

光影播放器不集成任何第三方 SDK：无统计 SDK、无广告 SDK、无推送 SDK、无分享 SDK、无崩溃上报、无支付、无账号登录。所有播放能力由 HarmonyOS 系统 Kit 提供（Media Kit、AVSession Kit、BackgroundTasks Kit、ArkUI Kit）。

5. 儿童保护

本应用不面向儿童设计，不涉及儿童个人信息。应用不提供任何面向儿童的交互或数据收集，也不做内容分级或儿童内容过滤。

6. 数据删除

  • 移入回收站：保留文件供恢复；彻底删除只处理 Cine 管理且可确认所有权的本地文件
  • 清空片库：设置页「清空片库」，删除全部 URI 与元数据
  • 截图清理：截图管理只清除应用内 JPEG 和记录，不删除相册中的图片；相册图片由您在系统图库中管理
  • 彻底清除：卸载应用，系统清除全部沙盒数据，已保存相册的图片仍保留

从列表移除与移入回收站不会删除本地文件；彻底删除将删除 Cine 管理的副本。请按操作确认中的说明选择。

7. 本声明的更新

如本声明有重大变更，将在应用内提示更新。当前版本未集成任何远程通知或推送能力，因此声明变更以应用版本更新形式提供。
